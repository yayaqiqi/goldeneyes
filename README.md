# GoldenEyes

KOOK 恋综角色扮演社区管理机器人。基于 [khl](https://github.com/TWT233/khl.py) 库与 KOOK API 交互，提供恋综创建、私约、心动信、心愿墙、戏录生成、个人档案、恋综游戏等功能。

## 功能概览

- **恋综管理**：创建/清空恋综、绑定角色个人频道、更改配置
- **玩家互动**：私约邀请、传纸条、送礼物、点歌、公共留言、心愿墙、心动信
- **对戏追踪**：自动识别对戏轮次与字数统计，超时检测与回戏提醒
- **戏录生成**：按角色生成带目录导航的 HTML 戏录文件、生成恋综纪念册
- **定时任务**：每日自动清理失效频道、结束超时对戏、提醒未回戏玩家

## 快速开始

### 环境要求

- Python 3.9+

### 安装依赖

```bash
pip install khl requests
```

### 配置

在 `data/` 目录下创建 `config.json`，填入 KOOK 机器人 Token：

```json
{
  "token": "你的机器人Token"
}
```

### 启动
#### 方式一：命令行
适用于所有操作系统
```bash
python main.py
```

#### 方式二
适用于windows,运行 `run.bat`

## 项目结构

```
├── main.py          # 机器人入口与全部命令逻辑
├── template.py      # KOOK 卡片消息模板构建
├── record.py        # HTML 戏录生成器
├── utils.py         # 时间工具函数
├── data/            # 运行时数据目录（JSON 存储）
│   ├── config.json  # 机器人 Token
│   ├── data.json    # 服务器-系列映射
│   └── <系列名>/    # 各系列玩家档案与信件数据
├── logfile/         # 运行日志
└── beifen/          # 旧版备份
```

## 命令一览

### 管理员命令

| 命令 | 说明 |
|------|------|
| `创建·恋综名称` | 创建新恋综 |
| `清空·恋综名称` | 删除恋综所有数据 |
| `绑定·恋综名称 角色名称 @玩家 @角色组` | 绑定角色到频道 |
| `移除绑定·恋综名称` | 解除频道绑定 |
| `更改信息·恋综名称 属性 key value` | 修改恋综配置 |
| `修正删除频道·恋综名称` | 清理失效频道数据 |
| `检查超时·恋综名称` | 结束超过72小时未回复的对戏 |
| `提醒回戏·恋综名称` | 提醒超过24小时未回戏的玩家 |
| `生成戏录·恋综名称 角色名称` | 生成角色 HTML 戏录 |

### 玩家命令

| 命令 | 说明 |
|------|------|
| `通讯·角色A&角色B` | 创建私密通讯频道 |
| `私约·EP名称` | 发起私约邀请 |
| `To角色名 内容` | 传匿名纸条 |
| `礼物·送礼对象` | 送礼物 |
| `点歌台` | 点歌 |
| `公共留言` | 发布公共留言 |
| `心愿·EP名称` | 发布心愿 |
| `心动信` | 提交心动信 |
| `撤回心动信` | 撤回已提交的心动信 |
| `个人档案` | 查看角色对戏进度 |
| `结束对戏` | 标记对戏完成 |
| `更新记录` | 手动刷新对戏记录 |
| `添加记录·EP名称` | 手动添加对戏记录 |

## 自动任务

每日 12:00（上海时间）自动执行：
- 清理已删除频道的残留记录
- 结束超过 72 小时的超时对戏
- 提醒超过 24 小时未回戏的玩家

## 对戏规则

在对戏频道中，每条消息的第一行必须是**当前发言角色的代号词**，机器人据此自动追踪轮次和字数：

```
小明
今天天气不错，我们去散步吧。

小红
好啊，去哪里呢？
```
